# TimeClock v1.0.0

定时提醒程序，使用Windows原生通知

## 功能特性

### 1. 定时提醒
- 设置每天固定的时:分:秒触发
- 每天到时间点后发送Windows原生通知
- 触发后保留在列表并保持启用

### 2. 倒计时提醒
- 设置倒计时时:分:秒
- 倒计时结束后发送Windows原生通知
- 触发后立即使用相同设置重新开始倒计时

### 3. 循环提醒
- 设置间隔时:分:秒
- 创建后立即开始计时，间隔到达后发送通知
- 触发后立即重新开始下一轮计时

```bash

```

## 使用说明

### 主界面
- 顶部：程序标题 + "新建提醒"按钮
- 中间：提醒列表（卡片样式）
- 底部：开机自启开关

### 新建提醒
1. 点击"新建提醒"按钮
2. 选择提醒类型（定时/倒计时/循环）
3. 输入时间（时:分:秒）
4. 输入通知标题和提醒内容
5. 点击"保存"

### 提醒卡片
每个提醒卡片包含：
- 类型标签（定时/倒计时/循环）
- 通知标题
- 时间 + 提醒内容预览
- 开关（启用/禁用）
- 编辑按钮
- 删除按钮

### 系统托盘
- 点击窗口"关闭"按钮，程序最小化到系统托盘
- 右键托盘图标可"显示窗口"或"退出"
- 点击窗口"最小化"按钮，最小化到任务栏

### 数据持久化
- 程序自动保存提醒列表到 `data.json`
- 重启程序后自动加载恢复

### 开机自启
- 底部开关可控制是否开机自启
- 通过Windows注册表实现

## 注意事项

1. **通知权限**：确保Windows通知设置中允许应用发送通知
2. **时间格式**：输入时间为24小时制
3. **通知显示**：通知显示10秒后自动消失
4. **程序退出**：请右键托盘图标选择"退出"，避免后台运行

## 技术栈

- Python 3.12+
- customtkinter：现代化GUI
- win10toast：Windows原生通知
- pystray：系统托盘图标
- pillow：图标图像处理
